## Echo Bot

The smallest possible bot — echoes back any text message. [Try in Playground →](/playground/)

```typescript
import { createBot } from "@effect-ak/tg-bot"

export default createBot().onMessage(({ text }) => [
  text(({ payload, ctx }) => ctx.reply(payload.text!))
])
```

## Command Bot

Handles `/start`, `/help`, and `/echo`. The `/echo` command dumps the raw message as JSON — handy for debugging and for learning what Telegram actually sends you. [Try in Playground →](/playground/)

```typescript
import { createBot } from "@effect-ak/tg-bot"

export default createBot().onMessage(({ command, text }) => [
  command("/start", ({ ctx }) => ctx.reply("Hello! Try /help or /echo")),
  command("/help", ({ ctx }) =>
    ctx.reply(
      "Available commands:\n/start — welcome message\n/help — this message\n/echo — your message as JSON"
    )
  ),
  command("/echo", ({ payload, ctx }) =>
    ctx.reply(`<pre language="json">${JSON.stringify(payload, null, 2)}</pre>`, {
      parse_mode: "HTML"
    })
  ),
  text(({ ctx }) => ctx.reply("Unknown command. Try /help"))
])
```

## File Bot

Converts any text message into a `.txt` file and sends it back. Shows how to use `ctx.replyWithDocument` — file uploads are just `{ file_content, file_name }`, no streams or form-data boilerplate. [Try in Playground →](/playground/)

```typescript
import { createBot } from "@effect-ak/tg-bot"

export default createBot().onMessage(({ command, text }) => [
  command("/start", ({ ctx }) => ctx.reply("Send me any text and I'll save it as a file")),
  text(({ payload, ctx }) =>
    ctx.replyWithDocument(
      {
        file_content: new TextEncoder().encode(payload.text!),
        file_name: "message.txt"
      },
      { caption: "Here's your text as a file" }
    )
  )
])
```

## Menu Bot (Inline Keyboard)

The whole UI is one message that gets rewritten in place as the user taps buttons. The navigation is declared as data with [`defineScreens`](/bot-runner/screens/): `next` is type-checked against screen ids, Back buttons, edit-in-place and `answer_callback_query` come for free. This bot runs live in the [Cloudflare Workers demo](https://github.com/kondaurovDev/tg-bot-sdk/tree/main/example).

```typescript
import { createBot, defineScreens } from "@effect-ak/tg-bot"

const screens = defineScreens({
  root: {
    text: "🏠 Main menu\n\nPick a section:",
    buttons: [
      [
        { label: "📋 Services", next: "services" },
        { label: "🕒 Hours", next: "hours" }
      ],
      [{ label: "☎️ Contacts", next: "contacts" }]
    ]
  },
  services: {
    text: "📋 Services\n\n• Consultation\n• Diagnostics",
    parent: "root",
    buttons: [
      {
        label: "📅 Book",
        action: ({ ctx }) => ctx.answerCallbackQuery({ text: "Not in the demo", show_alert: true })
      }
    ]
  },
  hours: { text: "🕒 Mon–Fri 9:00–18:00", parent: "root" },
  contacts: {
    text: "☎️ +1 555 0100",
    parent: "root",
    buttons: [{ label: "🌐 Website", url: "https://tg-bot-sdk.website" }]
  }
})

export default createBot().use(screens)
```
